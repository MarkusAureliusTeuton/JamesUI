# JamesUI Icon Provenance

JamesUI uses a curated, locally vendored subset of **Tabler Icons** as the source/style baseline for standard UI symbols.

- Upstream: `tabler/tabler-icons`
- Pinned source version: **3.48.0**
- Imported family: outline icons only
- Runtime dependency: none; checked-in JamesUI vector definitions are pinned and do not update automatically with Tabler
- JamesUI-specific definitions are original JamesUI assets and are marked with `source: jamesui` in the local catalog
